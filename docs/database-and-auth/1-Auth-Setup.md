# Authentication Setup Guide (Supabase Auth)

**Target:** Setup robust, production-ready authentication using Supabase. The application requires Email/Password and Google OAuth integrations.

> **AI Implementation Note:** If reading this as an AI assistant, guide the developer through these exact steps in the Supabase Dashboard and Google Cloud Console. Provide the exact code snippets for the backend developer if they ask how to verify JWTs.

---

## 1. Supabase Project Initialization
1. Go to [Supabase Dashboard](https://supabase.com/).
2. Create a new project named **WayPoint**.
3. Choose a region closest to your primary user base (e.g., US East, ap-south-1).
4. Save the **Database Password** securely. You will need this if you ever connect via `psql` or pgAdmin.

---

## 2. Email & Password Authentication Configuration
Supabase enables Email authentication by default, but we need to configure it correctly for the hackathon environment.

### Steps in Supabase Dashboard:
1. Navigate to **Authentication** > **Providers** > **Email**.
2. **Enable Email Signup:** `ON`
3. **Confirm email:** `OFF` (Crucial for hackathons to avoid blocking testers waiting for emails).
4. **Secure passwords:** Enforce a minimum length of 8 characters.

### Frontend Integration Handoff:
- The frontend will use `@supabase/supabase-js` to call `supabase.auth.signUp()` and `supabase.auth.signInWithPassword()`.
- Your job is to make sure the provider is active and that the backend (FastAPI) knows how to verify the JWT tokens generated by Supabase (see Section 4).

---

## 3. Google OAuth Setup (SSO)
We want a seamless login experience via Google.

### Step 3.1: Google Cloud Console
1. Go to [Google Cloud Console](https://console.cloud.google.com/).
2. Create a new project: "WayPoint-Auth".
3. Navigate to **APIs & Services** > **OAuth consent screen**.
   - Choose **External**.
   - App name: `WayPoint`
   - User support email: (Your email)
   - Developer contact: (Your email)
4. Navigate to **Credentials** > **Create Credentials** > **OAuth client ID**.
   - Application type: **Web application**.
   - Name: `WayPoint-Web`.
   - **Authorized redirect URIs:** We need to get this from Supabase. (Go to Supabase > Authentication > URL Configuration, copy the `Site URL` which ends in `.supabase.co/auth/v1/callback`). Paste it here.
5. Save and copy the **Client ID** and **Client Secret**.

### Step 3.2: Supabase Dashboard
1. Go to **Authentication** > **Providers** > **Google**.
2. Enable the provider.
3. Paste the **Client ID** and **Client Secret** obtained from Google.
4. Save.

---

## 4. JWT Verification (Handoff to Backend Developer)
Supabase handles the signup/login, but the **FastAPI Backend** needs to verify that requests coming from the frontend are legitimate.

- When the frontend successfully logs in, it receives a **JWT (JSON Web Token)**.
- The frontend will send this token in the `Authorization: Bearer <token>` header to the FastAPI backend.
- **Your Job:** Ensure the backend developer has the `JWT_SECRET` from Supabase (found in **Project Settings > API > JWT Secret**). 

The backend will use this secret to cryptographically verify the user's identity on every API call without needing to query the database.
